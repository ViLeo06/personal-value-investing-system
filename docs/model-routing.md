# 模型路由

模型由公司经济特征决定，不按股票代码或个人喜好硬套。

| 公司类型 | 主模型 | 必做交叉检查 | 主要风险 |
|---|---|---|---|
| 普通消费、制造、成熟科技 | 企业自由现金流 | 反向估值、相对估值 | 增长、利润率、资本回报 |
| 高增长企业 | 收入→利润率→资本回报 | 反向估值、基础概率 | 市场空间、正常化利润率 |
| 银行 | 剩余收益 | 市净率、股利能力 | 净息差、信用成本、资本约束 |
| 保险 | 专用保险估值 | 内含价值与分部检查 | 负债久期、投资收益、假设稳定性 |
| 稳定高分红企业 | 股利折现、股权自由现金流 | 相对估值 | 分红可持续性、资本开支 |
| 地产或资产型企业 | 净资产价值 | 现金流、压力情景 | 资产质量、债务、折价 |
| 资源周期企业 | 中周期盈利、净资产／现金流 | 周期反向检查 | 商品价格、资本纪律 |
| 多业务集团 | 分部加总 | 整体现金流、折价 | 重复计算、总部成本 |

所有模型都必须输出：悲观／基准／乐观、关键假设、敏感因素、证伪条件和置信度。公司质量评分不得直接作为估值乘数。
