# 决策 0001：从干净历史重建

日期：2026-09-02  
状态：接受

## 背景

现有投资目录中同时存在轻量个人研究闭环和较重的估值／数据库工程。用户明确要求依据置顶聊天重新开始，并覆盖 GitHub 上的相关旧项目。

## 决策

- 新项目建立在 `investment/personal-value-investing-system/`。
- 不复制旧仓库代码；只迁移已确认的方法、需求和可复用原则。
- 旧本地项目、脏工作树和历史交接包原地保留。
- GitHub 旧主线先建立归档分支，再用带租约的强制推送替换默认分支。
- 新项目使用英文名 `personal-value-investing-system`。

## 结果

新历史更容易理解和审计，同时保留旧工程的恢复入口。未来如需复用旧代码，必须按具体模块重新评审和测试，不能整包回灌。
