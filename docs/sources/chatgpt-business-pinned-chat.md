# GPT 企业版置顶聊天迁移稿

来源标题：《探讨价值估值模型》  
读取日期：2026-09-02  
读取范围：全部十一轮可访问聊天  
迁移方式：结构化提炼，不把聊天中的历史数值当作当前事实；附件仅记录线索，不声称已取得文件。

## 用户已经确认的方向

1. 产品是个人价值投资决策系统，不是单一估值表。
2. 同时回答贵贱、合理价格和未来三至五年预期年化收益；典型周期确定为五年。
3. 首期市场为 A 股和港股。
4. 长期目标是输入股票代码后自动整理资料、重构财务、识别公司类型并选择模型，用户审视少数关键假设。
5. 五年预期年化十五个百分点是核心门槛之一，但必须叠加公司质量、不确定性和安全边际。
6. 面向金融初学者，专业概念要给白话解释；同时保留简版和可交给其他智能体的详版。
7. 输出使用区间、情景、关键假设和证伪条件，不追求小数点式假精确。
8. 历史验证必须使用当时可得信息，五年结果采用股东总回报。

## 方法组合

- 巴菲特／伯克希尔：好生意、所有者收益、安全边际和长期视角。
- 达摩达兰：现金流、再投资、增长与新增资本回报之间的约束。
- 麦肯锡：增长和资本回报是否真正创造价值。
- 晨星：护城河、三阶段竞争优势衰减和估值不确定性。
- 莫布森：竞争优势持续期、市场隐含预期和基础概率。
- 特许金融分析师体系：按公司类型选择模型并交叉验证。

## 系统主流程

股票代码 → 官方披露优先的数据层 → 财务重构 → 公司类型识别 → 商业模式／护城河／管理层／资本配置／财务质量／行业空间 → 投入资本回报与资本成本 → 基础概率约束 → 模型路由 → 三阶段估值 → 反向估值 → 三情景 → 五年预期内部收益率 → 目标价格 → 动态安全边际 → 关键分歧、风险和证伪条件。

## 三阶段估值

- 第一阶段：一至五年逐年经营预测。
- 第二阶段：六年至十五或二十年，增长、利润率和资本回报逐步向正常水平收敛。
- 第三阶段：成熟期，新增投入资本回报接近资本成本。

## 模型库

企业自由现金流、股权自由现金流、所有者收益、股利折现、剩余收益、分部加总、净资产价值、相对估值、反向现金流折现、五年内部收益率、情景分析和动态安全边际。

## 公司质量框架

建议总分一百分：商业模式与护城河二十五、资本效率二十、管理层与资本配置二十、财务质量十五、增长空间与行业结构二十。评分不得直接乘估值倍数，而应通过现金流、资本回报和竞争优势期影响估值。

护城河来源包括网络效应、转换成本、无形资产或牌照、成本优势和有效规模。

## 历史时点验证

- A 区只使用回测日之前可公开获得的信息，完成估值后冻结。
- B 区随后揭示未来经营和五年股东总回报。
- 每个参数都要有当时证据链，严禁看到结果后调整参数。
- 输出包括三情景价值、预期收益、目标价格、反向估值和证伪条件。
- 验证包括经营预测误差、股东总回报、最大回撤、指数基准、超额收益、收益预测误差和决策归因。
- A 股基准为沪深三百全收益；腾讯主基准为恒生总回报，恒生科技作为辅助。

首轮四家公司为贵州茅台、腾讯、比亚迪和招商银行。由于此前可能接触过后续结果，这轮只能称为“历史信息集约束复演”，不能称为真正盲测。四个样本也不能证明胜率或统计有效。

## 四家公司带来的模型问题

- 贵州茅台：拆解销量、价格和所有者收益，检验好公司与好价格的差异。
- 腾讯：处理平台现金流、投资资产、人工智能投入、资本开支和分部价值。
- 比亚迪：处理重资本成长、正常化利润率、规模效应、海外业务和新增资本回报。
- 招商银行：使用剩余收益，重点连接净息差、信用成本、长期净资产收益率、资本充足率和分红率。
